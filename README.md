## 👩‍💻 Overview

This repository presents my complete **Data Analyst Internship Portfolio**, showcasing an end-to-end data analytics project. The objective of this work is to transform raw data into meaningful insights and support business decision-making using analytical techniques.

The project demonstrates the full data analysis workflow:
**Data Cleaning → Exploration → Visualization → Storytelling → Statistical Validation**

---

## 🎯 Project Objective

- Analyze sales data to identify trends and patterns  
- Evaluate performance across categories, regions, and products  
- Build interactive dashboards for business users  
- Validate insights using statistical methods  
- Deliver actionable business recommendations

## 🔍 Project Breakdown

### 🧩 Task 1: Data Wrangling
- Cleaned and preprocessed raw dataset
- Handled missing values and inconsistencies
- Standardized column formats
- Performed feature engineering

---

### 📊 Task 2: Exploratory Data Analysis (EDA)
- Analyzed sales trends over time
- Evaluated category and regional performance
- Identified outliers and data patterns
- Generated meaningful visual insights

---

### 📈 Task 3: Dashboard Development
- Built interactive dashboard using Power BI
- Designed KPI-driven layout
- Implemented slicers for dynamic filtering
- Enabled business-level decision-making

---

### 🧠 Task 4: Data Storytelling & Statistical Validation
- Converted analysis into business narrative
- Performed Hypothesis Testing:
  - T-Test (category comparison)
  - Chi-Square Test (relationship analysis)
- Derived actionable recommendations

---

## 📊 Key Insights

- 📌 Technology category drives highest revenue  
- 📌 West region consistently outperforms others  
- 📌 Revenue is concentrated among top-performing products  
- 📌 Regional preferences significantly impact category performance  
- 📌 Operational factors like shipping influence outcomes  

---

## 🧪 Statistical Validation

- ✔ Independent T-Test → Validated category performance differences  
- ✔ Chi-Square Test → Confirmed relationship between region & category  
- ✔ Insights backed by statistical significance (p-value < 0.05)
